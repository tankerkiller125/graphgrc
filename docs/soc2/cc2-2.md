# SOC2 - CC2.2
## Principle
COSO Principle 14: The entity internally communicates information, including objectives and responsibilities for internal control, necessary to support the functioning of internal control.
## Points of Focus
### CC2.2.a: Communicates Internal Control Information
Communicates information for internal control responsibilities.
### CC2.2.b: Communicates With the Board of Directors
Provides information for board oversight roles.
### CC2.2.c: Provides Separate Communication Lines
Establishes separate channels for anonymous communication.
### CC2.2.d: Selects Relevant Method of Communication
Considers timing, audience, and nature of information.
### CC2.2.e: Communicates Responsibilities
Informs personnel about system control responsibilities.
### CC2.2.f: Communicates Information on Reporting Failures, Incidents, Concerns, and Other Matters
Provides reporting methods.
### CC2.2.g: Communicates Objectives and Changes to Objectives
Informs personnel of objectives and changes.
### CC2.2.h: Communicates Information to Improve Security Knowledge and Awareness
Provides security awareness training.
### CC2.2.i: Communicates Information to Improve Privacy Knowledge and Awareness
Provides privacy awareness training.
### CC2.2.j: Communicates Incident Reporting Methods
Informs of process to report suspected privacy incidents.
### CC2.2.k: Communicates Information About System Operation and Boundaries
Explains system design and operation.
### CC2.2.l: Communicates System Objectives
Communicates objectives to enable personnel to fulfill responsibilities.
### CC2.2.m: Communicates System Changes
Communicates changes that affect responsibilities.

# SOC2 - P4.2
## Principle
The entity retains personal information consistent with the entity's objectives related to privacy.
## Points of Focus
### P4.2.a: Retains Personal Information [P][C]
Retains only as long as necessary for stated purposes.
### P4.2.b: Protects Personal Information [P][C]
Prevents erasure during retention period.

# SOC2 - CC2.3
## Principle
COSO Principle 15: The entity communicates with external parties regarding matters affecting the functioning of internal control.
## Points of Focus
### CC2.3.a: Communicates to External Parties
Communicates relevant information to external parties.
### CC2.3.b: Enables Inbound Communications
Allows input from external parties via communication channels.
### CC2.3.c: Communicates With the Board of Directors
Reports external assessment results to the board.
### CC2.3.d: Provides Separate Communication Lines
Establishes anonymous communication channels for external parties.
### CC2.3.e: Selects Relevant Method of Communication
Considers timing, audience, nature, and legal requirements.
### CC2.3.f: Communicates Objectives Related to Confidentiality and Changes to Those Objectives
For confidentiality matters.
### CC2.3.g: Communicates Objectives Related to Privacy and Changes to Those Objectives
For privacy matters.
### CC2.3.h: Communicates Incident Reporting Methods
Provides process for reporting suspected privacy incidents.
### CC2.3.i: Communicates Information About System Operation and Boundaries
To external users.
### CC2.3.j: Communicates System Objectives
To appropriate external users.
### CC2.3.k: Communicates System Responsibilities
To external users with system responsibilities.
### CC2.3.l: Communicates Information on Reporting System Failures, Incidents, Concerns, and Other Matters
To external users.

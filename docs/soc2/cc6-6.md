# SOC2 - CC6.6
## Principle
The entity implements logical access security measures to protect against threats from sources outside its system boundaries.
## Points of Focus
### CC6.6.a: Restricts Access
Limits activities through communication channels.
### CC6.6.b: Protects Identification and Authentication Credentials
Secures credentials during transmission.
### CC6.6.c: Requires Additional Authentication or Credentials
Implements additional authentication for external access.
### CC6.6.d: Implements Boundary Protection Systems
Configures firewalls and other security systems.

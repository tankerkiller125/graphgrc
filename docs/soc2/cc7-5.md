# SOC2 - CC7.5
## Principle
The entity identifies, develops, and implements activities to recover from identified security incidents.
## Points of Focus
### CC7.5.a: Restores the Affected Environment
Rebuilds systems and updates configurations.
### CC7.5.b: Communicates Information About the Incident
Informs stakeholders about recovery actions.
### CC7.5.c: Determines Root Cause of the Incident
Identifies underlying cause of incidents.
### CC7.5.d: Implements Changes to Prevent and Detect Recurrences
Updates controls based on analysis.
### CC7.5.e: Improves Response and Recovery Procedures
Enhances incident response plans.
### CC7.5.f: Implements Incident-Recovery Plan Testing
Tests recovery procedures periodically.

# SOC2 - P4.1
## Principle
The entity limits the use of personal information to the purposes identified in the entity's objectives related to privacy.
## Points of Focus
### P4.1.a: Uses Personal Information for Intended Purposes [P][C]
Uses information only for intended purposes with proper consent.

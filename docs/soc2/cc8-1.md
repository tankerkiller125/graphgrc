# SOC2 - CC8.1
## Principle
The entity authorizes, designs, develops or acquires, configures, documents, tests, approves, and implements changes to infrastructure, data, software, and procedures to meet its objectives.
## Points of Focus
### CC8.1.a: Manages Changes Throughout the System Life Cycle
Processes for entire system lifecycle.
### CC8.1.b: Authorizes Changes
Approves changes before design or acquisition.
### CC8.1.c: Designs and Develops Changes
Designs changes to support objectives.
### CC8.1.d: Documents Changes
Documents changes for ongoing maintenance.
### CC8.1.e: Tracks System Changes
Tracks changes prior to implementation.
### CC8.1.f: Configures Software
Selects and monitors configuration parameters.
### CC8.1.g: Tests System Changes
Tests changes before production implementation.
### CC8.1.h: Approves System Changes
Approves changes before implementation.
### CC8.1.i: Deploys System Changes
Implements changes with segregation of responsibilities.
### CC8.1.j: Identifies and Evaluates System Changes
Identifies objectives affected by changes.
### CC8.1.k: Identifies Changes in Infrastructure, Data, Software, and Procedures Required to Remediate Incidents
Initiates change process for incident remediation.
### CC8.1.l: Creates Baseline Configuration of IT Technology
Maintains baseline configurations.
### CC8.1.m: Provides for Changes Necessary in Emergency Situations
Includes expedited change processes.
### CC8.1.n: Manages Patch Changes
Manages patches for infrastructure and software.

# SOC2 - A1.1
## Principle
The entity maintains, monitors, and evaluates current processing capacity and use of system components (infrastructure, data, and software) to manage capacity demand and to enable the implementation of additional capacity to help meet its objectives.
## Points of Focus
### A1.1.a: Measures Current Usage
Establishes baseline for capacity management.
### A1.1.b: Forecasts Capacity
Projects usage against capacity and tolerances.
### A1.1.c: Makes Changes Based on Forecasts
Initiates change management when needed.

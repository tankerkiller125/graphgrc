# SOC2 - CC6.8
## Principle
The entity implements controls to prevent or detect and act upon the introduction of unauthorized or malicious software to meet the entity's objectives.
## Points of Focus
### CC6.8.a: Restricts Installation and Modification of Application and Software
Limits software installation privileges.
### CC6.8.b: Detects Unauthorized Changes to Software and Configuration Parameters
Monitors for unauthorized changes.
### CC6.8.c: Uses a Defined Change Control Process
Manages software implementation through change control.
### CC6.8.d: Uses Antivirus and Anti-Malware Software
Implements malware detection and remediation.
### CC6.8.e: Scans Information Assets From Outside the Entity for Malware and Other Unauthorized Software
Checks incoming assets.

# SOC2 - CC6.1
## Principle
The entity implements logical access security software, infrastructure, and architectures over protected information assets to protect them from security events to meet the entity's objectives.
## Points of Focus
### CC6.1.a: Identifies and Manages the Inventory of Information Assets
Inventories and classifies assets.
### CC6.1.b: Assesses New Architectures
Evaluates security of new architectures before implementation.
### CC6.1.c: Restricts Logical Access
Restricts access to assets through access control mechanisms.
### CC6.1.d: Identifies and Authenticates Users
Verifies identity of users, infrastructure, and software.
### CC6.1.e: Considers Network Segmentation
Isolates portions of the network based on risk.
### CC6.1.f: Manages Points of Access
Identifies and controls external access points.
### CC6.1.g: Restricts Access to Information Assets
Establishes access rules using data classification.
### CC6.1.h: Manages Identification and Authentication
Establishes requirements for system access.
### CC6.1.i: Manages Credentials for Infrastructure and Software
Controls access credentials for system components.
### CC6.1.j: Uses Encryption to Protect Data
Implements encryption based on risk assessment.
### CC6.1.k: Protects Cryptographic Keys
Secures keys during generation, storage, use, and destruction.
### CC6.1.l: Restricts Access to and Use of Confidential Information for Identified Purposes
For confidentiality.
### CC6.1.m: Restricts Access to and the Use of Personal Information
For privacy.

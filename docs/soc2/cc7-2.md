# SOC2 - CC7.2
## Principle
The entity monitors system components and the operation of those components for anomalies that are indicative of malicious acts, natural disasters, and errors affecting the entity's ability to meet its objectives; anomalies are analyzed to determine whether they represent security events.
## Points of Focus
### CC7.2.a: Implements Detection Policies, Procedures, and Tools
Establishes security event detection measures.
### CC7.2.b: Designs Detection Measures
Designs controls to identify various types of anomalies.
### CC7.2.c: Implements Filters to Analyze Anomalies
Processes to identify security events.
### CC7.2.d: Monitors Detection Tools for Effective Operation
Maintains effectiveness of detection tools.
